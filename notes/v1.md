# V1 — clean instrumented baseline

## Goal
Reproduce the random-baseline *search* behavior, but modular, logged, de-duplicated,
and producing **valid** candidates, with a measurable local score.

## What shipped
- `attack_framework/` package (config, utils, logger, prompt_library, trace_analyzer,
  evaluator, heuristics, archive, search, algorithm).
- `attack.py` shim + `experiments/run_local.py` harness with a gateway-faithful local
  scorer.

## Key finding: the stock random baseline emits INVALID candidates
The baseline uses one ever-growing episode, so candidate N carries all N messages.
The gateway caps candidates at 32 messages and **raises INVALID_SUBMISSION** on any
longer one — so the baseline's later candidates would fail the whole submission. In
our first run under the `allow` guardrail we saw 29 breaches but 0 returned
candidates: the archive correctly rejected the over-long chains.

**Fix (also a real improvement):** episodic search — reset between short trials so
every candidate is a self-contained chain of ≤ `episode_len` (default 6) messages.
The gateway replays each candidate from a fresh env anyway, so candidates *must* be
short + self-contained to reproduce.

100% replay fidelity (no phantom candidates). Random cannot beat rules/optimal.

## Corrections to earlier assumptions
- Diversity is keyed on `score_cell_signature = cell_signature(tool_events)` — tool
  events only, NOT user text. Reworded prompts that yield identical tool calls do
  NOT add diversity. (Corrected in `evaluator.score_cell_hash` + `docs/mechanics.md`.)
